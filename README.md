# Práctica V · Sitio web

Sitio web de **al menos 3 páginas**, con **CSS** propio y **responsive**.
Product Owner: el profesor y el jefe de proyecto de otro grupo.

## Estructura
```
index.html      página principal
*.html          resto de páginas (mínimo 2 más)
css/            hojas de estilo (estilos.css)
img/            imágenes
```

## Normas
- **Nunca** se trabaja en `main`. Ramas `feature/...` a partir de `develop`.
- Todo entra por **Pull Request** a `develop`; el jefe revisa y fusiona.
- Ver la **Wiki** para el flujo completo y las tareas.
