Desarrollo de la Web

  • Crear una web, de por lo menos 3 páginas, usando css. La web ha de ser responsive. El product owner de la web será el profesor y el jefe de proyecto de otro grupo.
  • De las tres tareas, el PO será el profesor, excepto en la web, que será el profesor y el jefe de proyecto de otro grupo.
